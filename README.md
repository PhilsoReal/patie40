# Patience’s surprise 40th birthday invitation

A complete static website for GitHub Pages. No installation or build required.

## Publish

1. Sign in to GitHub and create a repository named `patience40`. Select **Public**.
2. Extract this ZIP. Upload its contents directly to the repository root (not the enclosing folder). Ensure `index.html`, `styles.css`, `invitation.js` and the three image/icon files are together.
3. Commit the uploaded files to the `main` branch.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. Wait for the Pages deployment to finish. GitHub displays the live URL, normally `https://YOUR-USERNAME.github.io/patience40/`.

No ChatGPT branding or tracking code is included. Google Fonts are loaded externally; local fallback fonts are provided. The page requests search engines not to index it; this is not access control. The free public repository contains the invitation details, photo and RSVP link, and the website is public.

## Included features

- Cover with Open invitation button and return button
- Patience’s portrait and floral background
- Surprise reminder and organising committee draft labels
- 29 November 2026 at 12 pm
- Furzton Ridgeway Community Centre, 33 Dulverton Dr, Furzton, Milton Keynes MK4 1NA
- Google Maps location button
- WhatsApp RSVP to Carol with a prefilled message
- Partners and children welcome
- Responsive layout and reduced motion support

## Edit later

Change wording in `index.html`, appearance in `styles.css`, and cover behaviour in `invitation.js`. Asset paths are relative, so the site works in a GitHub project subdirectory or on a custom domain. There is no RSVP database; the RSVP button opens WhatsApp.
